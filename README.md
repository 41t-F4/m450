# M450 – Applikationen testen

Aufgaben-Repository von **Nicola Wehrli** für das Modul 450 (TBZ).

## Struktur

Pro Themenblock ein Ordner mit den gelösten Aufgaben:

| Ordner | Thema | Block |
|---|---|---|
| [grundlagen](grundlagen/) | Grundlagen Testing & Testing im Vorgehensmodell | Block 01 |
| [teststrategie](teststrategie/) | Teststrategie (Testfälle, Testmethoden) | Block 02 |
| [test-levels-unit-testing](test-levels-unit-testing/) | Test Levels & Unit Testing | Block 03 |
| [schnittstellen](schnittstellen/) | Schnittstellen / Test Doubles | Block 05 |
| [automation-testing](automation-testing/) | Automation Testing | Block 06 |
| [code-reviews](code-reviews/) | Code Reviews | Block 07 |
| [tdd](tdd/) | Test Driven Development | Block 08 |
| [ci-cd-pipeline](ci-cd-pipeline/) | CI/CD-Pipeline (Unit Tests, Reports, GitHub Actions) | Block 08 |

Die Pipeline für das Recipe-Planner-Backend läuft bei jedem Push unter
[Actions](https://github.com/41t-F4/m450/actions); der Coverage-Report wird auf GitHub Pages publiziert.

Die Modul-Unterlagen selbst sind nicht Teil dieses Repositories.
